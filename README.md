# Model-level Backdooring Bias Detection for Text-to-Image Diffusion Models

## Overview

This repository contains the two-stage framework used to detect model-level
backdooring bias in text-to-image diffusion models, including feature
extraction, detector training and inference, Stage-II verification, prompts,
configurations, and evaluation code. Diffusion checkpoints are not included
and must be provided by the user; features and result files are generated by
the pipeline.

## Full detection pipeline

1. Generate architecture-matched features with `classify/generate_features.py`
   and `configs/feature_jobs.json`.
2. Train/predict the canonical block-channel detector in
   `classify/classifier/feature_ablation.py`.
3. Aggregate prompt probabilities with
   `classify/evaluation/model_aggregation.py`:
   `stage1_score = mean(backdoor_probability)` and
   `stage1_prediction = int(stage1_score > threshold)`.
4. For Stage-I positives only, compute decision-free Stage-II measurements with
   `stage2_reference_dispersion_measurement.py`, then the benign veto with
   `stage2_perturbation_response_verifier.py`.
5. Apply the one-way veto in `classify/evaluation/final_decision.py` and compute
   TP/TN/FP/FN, Accuracy, TPR, FPR, and F1 with `metrics.py`.

Stage-II can change suspicious to benign; it can never change a Stage-I benign
model to backdoor.

The launcher reads machine-local paths from environment variables and reports
any missing value before starting. The following example runs SD2 detection;
the corresponding SD1.4, SD3.5, and FLUX variables are listed in
`configs/feature_jobs.json`.

```bash
export MODEL_ID=my_sd2_model
export TEST_MODEL_ID=/models/my_sd2_model
export SD2_CLEAN_REFERENCE_ID=/models/clean_sd2
export SD2_BACKDOOR_REFERENCE_ID=/models/backdoor_sd2
export BASE_MODEL_ROOT=/models/base
export OPENCLIP_CACHE_DIR=/models/openclip_cache
python classify/generate_features.py \
  --manifest configs/feature_jobs.json \
  --job intrinsic_sd2_test \
  --job reference_sd2_test
```

Files under `configs/model_splits/` preserve the model membership and ordering
used in the experiments without exposing server paths.

Use the released SD2 `wo_cross` detector and complete Stage-I/Stage-II as
follows; replace the model, SAM, and image-encoder paths as needed:

```bash
F=artifacts/features/test/sd2; P=artifacts/predictions/$MODEL_ID
python classify/classifier/feature_ablation.py --mode predict_all --variants wo_cross \
  --lfd_csv $F/lfd/$MODEL_ID/results.csv --latent_cosine_csv $F/latent_trajectory/$MODEL_ID/adjacent_z_cos.csv \
  --latent_norm_csv $F/latent_trajectory/$MODEL_ID/adjacent_z_norm.csv --latent_update_norm_csv $F/latent_trajectory/$MODEL_ID/adjacent_z_delta_norm.csv \
  --reference_latent_csv $F/reference_latent/$MODEL_ID/results.csv --image_similarity_csv $F/image_similarity/$MODEL_ID/results.csv \
  --activation_difference_csv $F/activation_difference/$MODEL_ID/results.csv --ablation_output_dir artifacts/detector_checkpoints/sd2 \
  --predict_output_dir $P --prompt_txt data/prompts/test.txt --model_id $MODEL_ID --architecture sd2
python classify/evaluation/model_aggregation.py --input $P/wo_cross.csv --output $P/stage1.csv --threshold 0.5
python classify/stage2/stage2_reference_dispersion_measurement.py --model_family sd2 --target_model_id "$TEST_MODEL_ID" \
  --clean_ref_model_id "$SD2_CLEAN_REFERENCE_ID" --backdoor_ref_model_id "$SD2_BACKDOOR_REFERENCE_ID" \
  --sam_weights /models/sam.pt --image_encoder_id /models/dinov2 --output_dir $P/stage2/$MODEL_ID
python classify/stage2/stage2_perturbation_response_verifier.py --input $P/stage2/$MODEL_ID/stage2_six_domain_result.json --architecture sd2 --output-csv $P/stage2.csv
python classify/evaluation/final_decision.py --stage1 $P/stage1.csv --stage2 $P/stage2.csv --output $P/final.csv
```

## Feature extraction

| Paper group | Artifact |
|---|---|
| LFD | per-prompt, per-step hidden-block tensors |
| latent trajectory | cosine, latent norm, adjacent-update norm CSVs |
| reference latent discrepancy | suspect/reference latent statistics |
| image similarity | OpenCLIP, LPIPS, MSE, SSIM, and HOG statistics |
| activation difference | flattened module-wise activation differences |

For parity with the confirmed paper run, OpenCLIP uses `ViT-L-14` without a
`pretrained` argument. The explicit `NONE_RANDOM_INITIALIZATION` sentinel in
the release preserves that historical call; changing it would change the
image-similarity features.

Architecture-aware detection uses the released `wo_cross` checkpoints for
SD1.4 and SD2 and the `full` checkpoints for SD3.5 and FLUX. The shared Stage-I
model threshold is 0.5.

## Additional experiments

Architecture-agnostic detection and prompt sensitivity are implemented in

## Environment setup

The paper environment used Python 3.10.20, PyTorch 2.7.1+cu118, CUDA Toolkit
11.8 (nvcc 11.8.89), and cuDNN 9.1.0. Create a clean Conda
environment from the repository root:

```bash
conda create -n backdoor-bias-detection python=3.10.20 -y
conda activate backdoor-bias-detection

pip install --index-url https://download.pytorch.org/whl/cu118 \
  torch==2.7.1+cu118 torchvision==0.22.1+cu118 torchaudio==2.7.1+cu118
pip install -r requirements.txt
```

Check the active runtime before generating features:

```bash
python --version
nvcc --version
python -c "import torch; print(torch.__version__, torch.version.cuda, torch.backends.cudnn.version()); print(torch.cuda.is_available())"
```

The recorded run used seeded best-effort reproducibility, not bitwise GPU
determinism: cuDNN deterministic mode and PyTorch deterministic algorithms were
disabled. Exact versions of the direct runtime dependencies are pinned in
`requirements.txt`.
